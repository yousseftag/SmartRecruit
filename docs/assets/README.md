# Documentation assets

Images and demo media referenced by the docs. Binary assets live here so pages stay text-only.

## Conventions

- One file per screen, `NN-feature.png`, numbered in reading order.
- PNG screenshots at 1920×1080, kept under ~300 KB each.
- Reference from docs with a relative path and descriptive alt text: `![Dashboard KPIs](../assets/01-dashboard-kpis.png)`.
- Update the affected screenshot when the UI changes; don't chase every micro-change.
